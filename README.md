# 📈 TradeX - Stock Trading Dashboard

TradeX is a modern stock trading dashboard built using React, Tailwind CSS, Firebase, and TradingView widgets.

It provides a clean fintech-style UI with live stock charts, stock search, authentication, and portfolio sections.

---

## 🚀 Features

- 🔐 Firebase Authentication
- 📊 Live TradingView Stock Charts
- 🔎 Real-Time Stock Search
- 🏦 Portfolio Dashboard
- 📱 Fully Responsive Design
- 🎨 Modern Fintech UI
- ⚡ Fast React + Vite Setup
- 📈 Company Logos
- 💹 Buy / Sell Interface

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Firebase
- React Router DOM
- Lucide React Icons
- TradingView Widget
- Vite
